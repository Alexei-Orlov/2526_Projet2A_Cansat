================================================================================
  3. NUAGE DE POINTS 3D (outil principal)
  Fichier : cloudPoints.py
================================================================================

  Usage de base :
    python cloudPoints.py

  Options :
    --input   -i  <fichier.csv>   Fichier LIDA_xxx.CSV              (defaut : data_in/LIDA_001.CSV)
    --phases      <phase(s)>      Phases a garder                   (defaut : drop)
    --min-range   <metres>        Distance minimale                  (defaut : 0.2)
    --max-range   <metres>        Distance maximale                  (defaut : 100.0)
    --boresight   <direction>     Orientation du LIDAR dans le corps (defaut : lidar_mount)
                                  Valeurs : forward backward left right up down lidar_mount
    --color-by    <colonne>       Colonne pour le code couleur       (defaut : distance)
                                  Valeurs speciales :
                                    distance   = distance mesuree (defaut)
                                    time       = temps relatif en secondes depuis le 1er hit
                                  Ou n'importe quel nom de colonne CSV (ex: altitude)
    --no-trajectory               Ne pas tracer la trajectoire du CanSat
    --alt-source  <source>        Source d'altitude pour la translation verticale
                                  Valeurs : baro = barometre (defaut, comportement historique)
                                            gnss = colonne gnss_alt (firmware recent uniquement)
                                  Avec gnss, la baro d'origine reste disponible dans la
                                  colonne altitude_baro pour comparaison
    --ignore-gps                  Ignorer lat/lon (fix bruyant) - garde seulement
                                  l'altitude (celle choisie par --alt-source)
    --ignore-baro                 Ignorer l'altitude (celle choisie par --alt-source)
                                  - garde seulement lat/lon
                                  (combine --ignore-gps + --ignore-baro pour nuage
                                   purement orientationnel, sans aucune translation)
    --no-slerp                    Desactiver l'interpolation SLERP entre bursts DMA
    --t-start     <secondes>      Ne garder que les hits a partir de ce temps,
                                  relatif au 1er echantillon du fichier    (defaut : non)
    --t-end       <secondes>      Ne garder que les hits jusqu'a ce temps,
                                  relatif au 1er echantillon du fichier    (defaut : non)
    --output-html <fichier.html>  Sauvegarder le graphe en HTML
    --export-xyz  <fichier.xyz>   Exporter le nuage en fichier texte x y z
    --no-show                     Ne pas ouvrir le navigateur

  Note : le nettoyage supprime les NaN, les distances hors plage min/max et
         les lignes a quaternion nul (loggees avant le demarrage de la fusion
         BNO055, inutilisables pour l'orientation).

  Exemples :
    python cloudPoints.py -i data_in/LIDA_001.CSV
    python cloudPoints.py -i data_in/LIDA_001.CSV --phases drop
    python cloudPoints.py -i data_in/LIDA_001.CSV --alt-source gnss
    python cloudPoints.py -i data_in/LIDA_001.CSV --color-by time
    python cloudPoints.py -i data_in/LIDA_001.CSV --color-by altitude
    python cloudPoints.py -i data_in/LIDA_001.CSV --ignore-gps
    python cloudPoints.py -i data_in/LIDA_001.CSV --ignore-gps --ignore-baro
    python cloudPoints.py -i data_in/LIDA_001.CSV --no-slerp
    python cloudPoints.py -i data_in/LIDA_001.CSV --output-html data_out/cloud.html --no-show
    python cloudPoints.py -i data_in/LIDA_001.CSV --export-xyz data_out/points.xyz --no-show
    python cloudPoints.py -i data_in/LIDA_001.CSV --phases drop ascension --boresight down
    python cloudPoints.py -i data_in/LIDA_001.CSV --min-range 0.5 --max-range 50.0
    python cloudPoints.py -i data_in/LIDA_001.CSV --phases --t-start 5 --t-end 30

  Combinaison complete (sauvegarder + exporter sans afficher) :
    python cloudPoints.py -i data_in/LIDA_001.CSV --output-html data_out/cloud.html --export-xyz data_out/points.xyz --no-show


================================================================================
  4. DASHBOARD TELEMETRIE + RAPPORT
  Fichier : Analysis_Tools\Basic\analyze_telemetry.py
================================================================================

  Usage de base (affichage interactif) :
    python Analysis_Tools\Basic\analyze_telemetry.py data_in/DATA_001.CSV

  Options :
    input         <fichier.csv>   Fichier DATA_xxx.CSV              (obligatoire)
    --output  -o  <dossier>       Dossier de sortie (PNG + rapport) (defaut : affichage)
    --plots   -p  <cles/numeros>  Sous-ensemble de courbes a afficher, separees
                                  par des virgules : par cle (ex: altitude,battery)
                                  ou par numero 1-based (ex: 1,5)  (defaut : toutes)
    --list-plots                  Liste les courbes disponibles (cle + numero) et quitte
    --t-start     <secondes>      Ne garder que les lignes a partir de ce temps,
                                  meme echelle que l'axe des graphes
                                  (tx_timestamp_ms/1000), ex: --t-start 1500 pour
                                  sauter une longue attente GO_FOR_LAUNCH   (defaut : non)
    --t-end       <secondes>      Ne garder que les lignes jusqu'a ce temps
                                  (meme echelle)                            (defaut : non)

  Cles disponibles (voir --list-plots) :
    1. accel  2. gyro  3. orientation  4. temperature  5. altitude
    6. vspeed  7. latitude  8. longitude  9. satellites  10. battery

  Produit :
    DATA_001_analysis.png   - Dashboard 10 subplots (accel, gyro, orientation,
                              temperature, altitude, vitesse verticale, GPS, batterie)
                              Chaque subplot a des bandes colorees par phase de vol.
                              Avec --plots, seules les courbes selectionnees sont tracees.
    DATA_001_report.txt     - Rapport texte : overview, altitude, vitesse, GPS,
                              batterie, temperature, phases avec durees

  Note : --t-start/--t-end ne modifient jamais le CSV source, uniquement les lignes
         prises en compte pour ce graphe/rapport (recadrage, pas de renumerotation
         des donnees brutes). Le rapport rappelle la fenetre effective utilisee.

  Exemples :
    python Analysis_Tools\Basic\analyze_telemetry.py data_in/DATA_001.CSV
    python Analysis_Tools\Basic\analyze_telemetry.py data_in/DATA_001.CSV --output data_out/rapport
    python Analysis_Tools\Basic\analyze_telemetry.py data_in/DATA_001.CSV -o data_out/out
    python Analysis_Tools\Basic\analyze_telemetry.py data_in/DATA_001.CSV --list-plots
    python Analysis_Tools\Basic\analyze_telemetry.py data_in/DATA_001.CSV --plots altitude,battery
    python Analysis_Tools\Basic\analyze_telemetry.py data_in/DATA_001.CSV --plots 1,5 -o data_out/out
    python Analysis_Tools\Basic\analyze_telemetry.py data_in/DATA_001.CSV --t-start 1500 --t-end 2190 -o data_out/out


================================================================================
  5. ANALYSES AVANCEES (rotation, GPS, energie, anomalies, KML)
  Fichier : Analysis_Tools\Advanced\advanced_analysis.py
================================================================================

  Usage de base :
    python Analysis_Tools\Advanced\advanced_analysis.py data_in/DATA_001.CSV

  Options :
    input         <fichier.csv>   Fichier DATA_xxx.CSV              (obligatoire)
    --output  -o  <dossier>       Dossier de sortie   (defaut : data_out/advanced_analysis_output)
    --mass        <kg>            Masse du CanSat en kg, utilisee pour l'energie
                                  potentielle/cinetique                (defaut : 0.5)
    --t-start     <secondes>      Ne garder que les lignes a partir de ce temps,
                                  meme echelle que l'axe des graphes
                                  (tx_timestamp_ms/1000)                    (defaut : non)
    --t-end       <secondes>      Ne garder que les lignes jusqu'a ce temps
                                  (meme echelle)                            (defaut : non)

  Produit :
    rotation_analysis.png   - Gyro X/Y/Z + magnitude de rotation
    gps_trajectory.png      - Vue de dessus + altitude vs distance horizontale
                              (saute si GPS = 0)
    energy_analysis.png     - Energie potentielle + cinetique + totale
                              (Ep = mgh, Ec = 1/2 m v^2, avec la masse --mass)
    flight_trajectory.kml   - Export Google Earth (saute si GPS = 0)
    analysis_report.txt     - Rapport texte avec stats + anomalies detectees

  Anomalies detectees automatiquement :
    - Gaps de donnees > 3x l'intervalle median
    - Sauts GPS > ~110 m entre deux lignes consecutives
    - Saturation accelerometre > 15 m/s2
    - Pics de temperature > 5 deg C entre deux lignes consecutives

  Exemples :
    python Analysis_Tools\Advanced\advanced_analysis.py data_in/DATA_001.CSV
    python Analysis_Tools\Advanced\advanced_analysis.py data_in/DATA_001.CSV --output data_out/out
    python Analysis_Tools\Advanced\advanced_analysis.py data_in/DATA_001.CSV --mass 0.175 -o data_out/out
    python Analysis_Tools\Advanced\advanced_analysis.py data_in/DATA_001.CSV --t-start 1500 --t-end 2190 -o data_out/out


================================================================================
  6. FONCTIONNALITES PHYSIQUES (Cd, parachute, batterie)
  Fichier : Analysis_Tools\Advanced\advanced_features.py
================================================================================

  Usage de base :
    python Analysis_Tools\Advanced\advanced_features.py data_in/DATA_001.CSV

  Options :
    input         <fichier.csv>   Fichier DATA_xxx.CSV              (obligatoire)
    --output  -o  <dossier>  Dossier de sortie (defaut : data_out/advanced_features_output)
    --mass        <kg>            Masse du CanSat en kg             (defaut : 0.5)
    --area        <m2>            Section transversale en m2 pour Cd (defaut : 0.01)
    --t-start     <secondes>      Ne garder que les lignes a partir de ce temps,
                                  meme echelle que l'axe des graphes
                                  (tx_timestamp_ms/1000)                    (defaut : non)
    --t-end       <secondes>      Ne garder que les lignes jusqu'a ce temps
                                  (meme echelle)                            (defaut : non)

  Produit :
    drag_coefficient.png     - 4 panneaux : altitude DROP, vitesse verticale,
                               vitesse vs altitude, infos Cd numeriques
                               (saute si < 10 lignes en phase DROP)
    parachute_deployment.png - Detection du moment d'ouverture du parachute :
                               altitude, vitesse verticale, acceleration verticale
    power_consumption.png    - Tension batterie + capacite restante estimee
                               + resume par phase

  Note : Cd = 2mg / (rho * v_terminal^2 * A)
         Detection parachute = pic max de l'acceleration verticale (jerk vers le haut)

  Exemples :
    python Analysis_Tools\Advanced\advanced_features.py data_in/DATA_001.CSV
    python Analysis_Tools\Advanced\advanced_features.py data_in/DATA_001.CSV --output data_out/out
    python Analysis_Tools\Advanced\advanced_features.py data_in/DATA_001.CSV --mass 0.35 --area 0.008
    python Analysis_Tools\Advanced\advanced_features.py data_in/DATA_001.CSV --mass 0.35 --area 0.008 -o data_out/out
    python Analysis_Tools\Advanced\advanced_features.py data_in/DATA_001.CSV --t-start 1500 --t-end 2190
